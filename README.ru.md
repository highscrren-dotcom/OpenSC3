# OpenSC3

[English](README.md) · Русский

**OpenSC3** — открытый пульт под Linux для USB-микшера **fifine AmpliGame SC3** (USB `3142:0c33`, MVsilicon
BP1048B2). Под Linux FIFINE для SC3 ничего не выпускает; система видит его как обычную USB-звуковую карту, а всё
остальное — усиления, встроенные эквалайзер и эффекты голоса, смена голоса, тональность автотюна — спрятано за
вендорским HID-интерфейсом, который ядро не берёт. OpenSC3 говорит с ним напрямую.

**Состояние: пре-альфа**, разработано и проверено на одной машине (CachyOS, KDE Plasma 6 Wayland, PipeWire).
Поддерживается только прошивка **V22**.

## Что умеет

- **Окно в виде самого микшера** (Qt/QML), вид сверху. Повторяет физические ползунки в реальном времени,
  показывает, какой из шести голосов и какая нота ELECTRIC (автотюн) включены, угадывает аппаратные клавиши MUTE,
  показывает уровни входа и выхода из PipeWire. Значок в трее — mute и подключение.
- **Mute микрофона** из окна и трея (через PipeWire — как mute в регуляторе громкости KDE).
- **Поправка MIC** — программное усиление поверх физического ползунка Mic, записывается в SC3 (влияет на то, что
  получает компьютер, а не на наушники). По умолчанию выключено: включите «Разрешить запись в SC3» в настройках окна.
- **Командная строка** `sc3`: проверка установки, понятная сводка, полный дамп, проверка эфира и экспериментальная
  запись, по умолчанию — сухой прогон (`sc3 set`, `sc3 profile`, `sc3 undo`).
- **Помнит про эфир:** пока OBS ведёт трансляцию или запись, OpenSC3 к управляющему каналу микшера не обращается
  вовсе (OBS спрашивается через obs-websocket, только чтение).

Чего SC3 на заводской прошивке не позволяет: его кнопки ничего не шлют компьютеру (повесить на них действия
нельзя), а ползунки Headphone / Line Out, MIC MONITOR, 48V и подсветка программе не видны.

## Сначала — безопасность

В протоколе есть команды, которые перепрошивают устройство или вешают управляющий канал. OpenSC3 перед первым
запросом сверяет дескриптор интерфейса и сборку прошивки, никогда не шлёт HID Feature-запросы, не трогает
конфигурацию USB и опрашивает не чаще раза в 0,5 с (проверено 15 минутами на устройстве). Запись — только по
короткому белому списку (поправка MIC, эквалайзер голоса, шумодав), по одному кадру, каждый читается обратно и при
расхождении откатывается, всё пишется в журнал и возвращается командой `sc3 undo`; запись не переживает отключения
питания (полный сброс — выдернуть USB). Тест проверяет исходники на всё, что выходит за эти правила. Подробно —
[docs/WRITE.md](docs/WRITE.md), [docs/GOTCHAS.md](docs/GOTCHAS.md), [docs/RESEARCH.md](docs/RESEARCH.md).

## Установка

Нужно: Python ≥ 3.11, `libusb`, `pyside6` + `qt6-declarative` для окна, PipeWire с `wpctl` и `pw-record`;
по желанию `python-websockets` (статус эфира OBS), `python-pyudev`, `python-evdev`.

```sh
git clone https://github.com/highscrren-dotcom/OpenSC3.git && cd OpenSC3
sudo install -m 644 udev/70-fifine-sc3.rules /etc/udev/rules.d/
sudo udevadm control --reload
sudo udevadm trigger --action=change --attr-match=idVendor=3142 --attr-match=idProduct=0c33
python3 -m opensc3 doctor      # проверяет установку, к устройству ничего не шлёт
python3 -m opensc3 install     # ярлык в меню и значки трея для пользователя (без sudo); --autostart — запуск в трей
```

Правило udev даёт доступ (`uaccess`) только к SC3 и только вошедшему пользователю — без группы `input`. Черновик
пакета для Arch — [packaging/arch](packaging/arch) (в AUR пока нет).

## Использование

```sh
python3 -m opensc3.app         # окно и трей (после install — «OpenSC3» в меню приложений)
python3 -m opensc3 status      # понятная сводка, ~20 чтений
python3 -m opensc3 live        # идёт ли эфир или запись в OBS?
python3 -m opensc3 set mic.trim 3            # сухой прогон: показывает кадры, ничего не шлёт
python3 -m opensc3 set mic.trim 3 --write    # запись (только вне эфира), вернуть: python3 -m opensc3 undo --write
```

После установки пакетом те же команды — `sc3 …` и `opensc3` (окно).

## Оговорка

OpenSC3 — неофициальный проект, не связан с FIFINE и MVsilicon и не одобрен ими. «FIFINE» и «AmpliGame» — товарные
знаки их владельцев; «SC3» лишь называет совместимую модель. Прошивки и данных производителя в репозитории нет.
Используйте на свой страх и риск.
