# Замысел и этапы

Полноценное приложение под Linux для fifine AmpliGame SC3 — по образцу GoXLR Utility: служба держит устройство,
клиенты (командная строка, веб-панель, док OBS, виджет KDE) говорят со службой. Работает на заводской прошивке V22.

## Что умеет SC3 по USB (основа — `RESEARCH.md`)

| | Читать | Менять (живёт до отключения питания) |
|---|---|---|
| Сборка, загрузка процессора, частота DSP | ✓ | — |
| Mute микрофона, цифровая громкость (≈ ползунок Mic), PGA/boost, ФВЧ | ✓ | возможно (по разрешению) |
| Ползунок Line In (`0xB6`), усиления (`0xA7`–`0xB6`) | ✓ | ✓ |
| Ползунки Headphone, Line Out | ✗ (только патчем прошивки) | ✗ |
| Гейт AGC1, экспандер, DRC, EQ голоса | ✓ | ✓ |
| Режим голоса / ELECTRIC (по флагам узлов) | ✓ | ✓ — свои голоса, хроматический автотюн |
| Кнопки | consumer-HID на 8 медиаклавиш — что шлёт панель, проверяем | — |
| Подсветка | ✗ | ✗ (только чужой прошивкой) |

## Архитектура

```text
            ┌──────────── sc3d (служба пользователя, systemd) ────────────┐
SC3 ──USB── │ usb.py → device.py (чтение) → state ─┬─ профили (TOML)       │
  кнопки ── │ evdev (grab по желанию) → mapper ────┤─ LiveGuard (эфир?)    │
            │ pyudev: подключение/отключение ──────┘─ obs-websocket         │
            └───────── API: ws://127.0.0.1:<порт> (JSON, только localhost) ─┘
                 ↑              ↑                  ↑                ↑
              sc3 (CLI)    веб-панель / док OBS   оверлей эфира   виджет KDE (позже)
```

- **Один владелец устройства** — служба. Клиенты не трогают USB, только API. Опрос — редкий и по необходимости.
- **Профили** («Подкаст», «Как с завода», «Без обработки», свои голоса) — наборы значений узлов; служба применяет
  выбранный при каждом подключении SC3 (запись не переживает отключение питания).
- **«Как с завода»** без выдёргивания кабеля: кадры пресета №8 из `.MVA` пользователя (не из репо — решение 5).
- **LiveGuard:** пока идёт эфир или запись — никаких записей в SC3 и действий в OBS, кроме явно разрешённых
  флагом `--live`.
- **Журнал** действий; уведомление KDE «SC3 отключён — голоса в эфире нет».

для статуса и профилей.
