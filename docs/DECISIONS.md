# Решения проекта

С обоснованием, ценой и условием пересмотра: через месяц важнее понять «почему», чем «что».

## 1. Отдельный проект, полноценное приложение под Linux (2026-10-07)

**Решение владельца.** Разведка SC3 начиналась в `stream-style` как «демон-пульт для эфира»; владелец решил делать
полноценное приложение отдельным проектом. Под Linux для SC3 нет ничего (только Windows-утилиты), образец по
устройству — GoXLR Utility (служба + веб-панель).
**Цена:** два репозитория. Звук эфира (эквалайзер PipeWire, фильтры OBS) остаётся в `stream-style`.

## 2. Ядро — stdlib + системная libusb через ctypes (2026-10-07)

- **Не hidraw:** у интерфейса 4 нет конечных точек, usbhid его не берёт — hidraw не будет никогда.
- **Не hidapi:** его libusb-бэкенд всегда запускает поток чтения interrupt-точки (её нет) и отцепляет драйвер у
  открываемого интерфейса — лишний риск отобрать кнопки у evdev.
- **Не pyusb:** лишняя зависимость ради трёх control-запросов; в примерах pyusb первой строкой `set_configuration()`,
  которая рвёт звук.
- **Плюс:** ноль зависимостей у ядра, весь доступ к USB в одном файле (`usb.py`), тест-сторож по исходникам.
**Пересмотр:** если понадобится асинхронный ввод-вывод или Windows/macOS.

## 3. Только заводская прошивка, не шьём (2026-10-07)

Оценка — `RESEARCH.md` §6: польза патчей для пульта и звука мала, способ — Windows-утилита со стиранием флеша или
перенос протокола загрузчика, при сбое — программатор SOIC-8. Проверенный образ V22 лежит локально для отката.
**Пересмотр:** если кнопки панели окажутся немыми, а пульт нужен именно на SC3; или ради своих голосов на кнопках.

## 4. Сначала только чтение; запись — отдельно (2026-10-07)

В `protocol.py` нет кадров записи. Запись появится отдельным модулем с собственным белым списком (какие узлы и
параметры, какие диапазоны), тестами на запрещённое и проверкой «эфир не идёт». Каждая новая категория записи —
по разрешению владельца.
**Почему:** любая ошибка в записи бьёт по живому звуку; у `0x01`/`0x11`/Feature последствия хуже.

## 5. Чужие данные не в репо (2026-10-07)

Прошивка Fifine, её расшифровка, пресеты и имена 54 узлов — данные Fifine/MVsilicon. Так же поступил dank0i: имена
приложение читает с устройства (`0x80`), пресеты — из `.MVA`, который пользователь даёт сам. Тесты — на синтетике;
допустимы числа регистров нашего экземпляра (они не чьё-то произведение).

## 6. Форма приложения — служба + клиенты + CLI (2026-10-07)

Служба `sc3d` — единственный владелец устройства; окно, CLI и прочее — её клиенты. Детали — `PLAN.md`.
Веб-панель как основная форма **отменена** решением 7. Открыто: лицензия.

## 7. Нативное окно на Qt 6 (PySide6 + QML), вид — сама панель SC3 (2026-10-07)

**Решение владельца:** полноценное приложение, не браузерное; выглядит как сам микшер; дизайн выбираем вместе по
картинкам, отрендеренным локально. Тулкит выбран архитектором и подтверждён разведкой (`design/spike/`):
PySide6 + QML (Kirigami — для обычных страниц настроек).
- **Почему Qt:** родной тулкит Plasma; трей (StatusNotifierItem), уведомления, один экземпляр через D-Bus, слой
  overlay (LayerShellQt) проверены на s1dPC; скевоморфные контролы — декларативно поверх `QtQuick.Templates`;
  зависимости для AUR — только официальные пакеты (`pyside6`, `qt6-declarative`).
- **Не GTK4/libadwaita:** каждый контрол рисовать вручную через GtkSnapshot, плоский Adwaita мешает, трея нет.
- **Не Slint:** привязок нет в репозиториях Arch, интеграции с Plasma нет.
- **Отрисовка для выбора дизайна:** `QQuickRenderControl` в OpenGL FBO, без окон; нужен `QT_QUICK_BACKEND=rhi`.
**Цена:** эффекты (`MultiEffect`) пропадают на software-бэкенде — элементы со свечением/тенью нужен запасной вид.
**Бриф дизайна** (ответы владельца на 10 вопросов) — `design/BRIEF.md`.
**Пересмотр:** если понадобится Windows/macOS-клиент или док OBS (тогда — лёгкий веб-клиент к API службы).

## 8. Mute микрофона из программы — mute входа SC3 в PipeWire, как в KDE (2026-10-07, уточнено 08.10)

**Решение владельца.** «Заглушить микрофон» в окне и трее — mute источника SC3 в PipeWire (`wpctl set-mute`), то же,
что щелчок mute в регуляторе громкости KDE. Глушит всё сразу: и OBS (через фильтр `s1dd1_voice`), и Discord (он берёт
SC3 напрямую). Работает и в эфире.
**Оговорка (найдено агентом «ядро» 07.10):** WirePlumber выполняет этот mute аппаратным «Mic Capture Switch» (Feature
Unit USB Audio) — это одна стандартная USB-аудиокоманда к SC3 по нажатию, **не ACP**. Владелец принял: так же делает
KDE. Клавиша MUTE на корпусе при этом не загорается (это отдельный Mute процессора, ACP).
**Отвергнуто:** mute фильтра `s1dd1_voice` — чисто программный, но Discord продолжил бы слышать.
**Позже (этап 3):** вне эфира — по желанию аппаратный Mute SC3 через ACP, чтобы горела клавиша.
**Пересмотр:** если mute через UAC хоть раз вызовет щелчок, провал звука или зависание SC3.

## 9. Постоянный опрос разрешён: одно чтение ACP раз в 0,5 с (2026-10-08)

**Основание — стенд этапа 2** (`research/stand.py`, 08.10 21:21–21:36, вне эфира, вместе с владельцем): 900 с, 1800
чтений `0x07`, 0 неудач (4 повтора внутри `Sc3`), задержка медиана 12,5 мс / p99 14,4 мс / макс 274 мс, пропусков
слотов 0, новых строк ядра про USB 0, xrun входа SC3 0, формат и квант не менялись. Владелец двигал ползунок Mic —
23 смены значения, ответы свежие, не кэш.
**Решение:** окно опрашивает SC3 не чаще **одного чтения раз в 0,5 с** (та же нагрузка, что на стенде) — только пока
окно видно и эфира нет; три неудачи подряд — опрос выключается до переподключения. Полные наборы чтений — по-прежнему
не чаще раза в 5 с.
**Выход проверен 09.10:** 5,5 минуты музыки в наушники при открытом окне — 0 xrun у входа и выхода SC3 (`pw-top`),
журнал ядра чист. Владелец слышал треск в наушниках, но он остался и после закрытия окна — не опрос.
**Пересмотр:** любой провал звука, зависание SC3 или ошибки USB в журнале ядра под опросом.

## 10. Имя — OpenSC3, лицензия — MIT (2026-10-09)

**Решение владельца.** Программа и репозиторий — **OpenSC3** («открытый пульт для SC3»): имя по устройству, без
товарных знаков Fifine («fifine», «AmpliGame» в имени не используем; «SC3» — номер модели, допустим как указание
совместимости). В README — оговорка, что проект не связан с Fifine. Лицензия **MIT** (как dank0i/sc3).
Пакет `sc3linux` → `opensc3`, окно — команда `opensc3`, CLI остаётся `sc3`.
**Цена:** переименование по всему репозиторию; каталог `~/dev/sc3-linux` пока не трогаем (на нём завязаны память
Claude и рабочая папка VS Code) — владелец переименует сам, когда удобно.
