# Грабли

Читать до правки `usb.py`, `protocol.py`, `device.py` и до любого обращения к устройству. Источник каждой — в скобках.

## Устройство и протокол

- **Ответ — кэш.** GET_REPORT отдаёт последний построенный ответ; на неотвеченную команду устройство повторяет
  ПРЕДЫДУЩИЙ. Без сверки ctrl мёртвая команда выглядит живой (dank0i). У `0x80` ctrl совпадает всегда — сверять эхо
  индекса.
- **Повторы важнее пауз.** 10 мс и 4 повтора — 0 % потерь; 50 мс — теряется всё (dank0i). Всегда считать ok/fail:
  тихий провал выглядит как «ничего не изменилось».
- **Выше `0xB6` — не читать:** мусор, затем весь ACP молчит тысячи запросов (dank0i).
- **`0xFE`** — OTA: любой кадр запускает таймер ухода в загрузчик (SDK; в сборке V22 ветки не нашли, запрет остаётся).
- **Feature-запросы**: SET с `0x55`/`0xAA` взводит обновление, следующий GET уводит в загрузчик `0000:2244`
  (RGB-Plus, fifine-am8).
- **`0x01` запись** — сон/перезагрузка/заводские настройки; **`0x11`** с `body[0]=1` пишет сектор флеша (SDK).
- **Запись в `0xB9`–`0xE4`** перезапускает USB-звук на ~8 с (dank0i) — нам не грозит, мы выше `0xB6` не ходим.
- **Чтение `0x02`** уменьшает счётчик AutoRefresh — побочный эффект безобидный (SDK).
- **Процессор SC3 занят на ~87 %** (наш `0x02`). Частый опрос у RGB-Plus подвешивал микшер и звук.
- **Ответ `0x00` — сборка, не номер Fifine:** `31 00 01 01 01 21 05` = чип 0x31, конфигурация 0.1.1, библиотека 1.33.5.
- **DRC: одиночная запись по индексам 3–7 — группы** по 2–3 значения, не одно слово (SDK).
- **Тональность автотюна — буква ASCII** (`C` = 67, бемоли строчными, `X` — хроматический) (SDK).
- **Внутри SC3 — 44,1 кГц**; USB 48 кГц пересчитывается ресемплерами самого SC3 (строки в прошивке, `0x01`).

- **Кнопки панели компьютеру не сообщают ничего** (заводская V22): ни HID, ни события — 0 за три записи 08.10.
  Голос, ELECTRIC, ползунки окно узнаёт только опросом ACP.
- **MUTE MIC / MUTE LINE IN = громкость 0.** Флаг mute в `0x07` не используется; MUTE байт в байт равен «ползунок
  внизу». Отличить можно только по времени: скачок в 0 между соседними чтениями (08.10).
- **ELECTRIC: точки панели идут по строкам**, а буква в `0x86` — по кругу SDK; подпись на панели ≠ нота SDK. Три
  точки верхнего ряда этого не показывают — проверять нижний ряд (08.10).

## Linux

- **usbhid не берёт интерфейс 4** («couldn't find an input interrupt endpoint») — hidraw для ACP не будет.
- **usbfs: control-запрос к чужому интерфейсу 3** (его держит usbhid) — EBUSY. Дескриптор интерфейса 3 брать из sysfs.
- **Захватить интерфейс 4 до первого запроса**, иначе usbfs захватит сам и напишет предупреждение в журнал.
- **Control-запросы требуют права на запись** к `/dev/bus/usb/…` (`devio.c`: `FMODE_WRITE`) — отсюда этап 2 udev.
- **Номера `hidrawN`/`eventN` и адрес USB меняются** после перезагрузки — только by-id и VID:PID.
- **Серийник `20190808` общий** для устройств на SDK MVsilicon (и у SC8, и у AM8) — опознавать по VID:PID.
- **uaccess**: правило должно идти раньше `73-seat-late.rules` (номер 70 подходит).
- **fish**: heredoc нет; команды для владельца — файлом или по одной строке.
- **KDE** забирает медиаклавиши любого устройства; если кнопки SC3 их шлют — EVIOCGRAB или `LIBINPUT_IGNORE_DEVICE`.

- **`pgrep -f`/`pkill -f` находят собственную оболочку**: строка запущенной команды содержит тот же шаблон —
  `pkill -f "opensc3 listen"` убил сам себя (код 144). Шаблон `[o]pensc3 …` или точный PID (08.10).

## Звук (замеры 07.10)

- Гейта на SC3 нет (AGC1 и экспандер выключены); «нули в паузах», виденные раньше, — скорее всего, усечение цифровой
  громкости при низком ползунке Mic.
- Шум входа −52 dBFS, из них ~80 % — инфразвук 5–20 Гц (ФВЧ АЦП на 20 Гц); слышимый ≈ −62 dBFS.
